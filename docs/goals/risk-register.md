# Risk register — the road from H13 to alpha and beyond

> Living table (ADR-0037 follow-up). Each risk carries the **earliest mechanical signal** that it
> is going wrong — a check or event, never a feeling — and the standing mitigation. Update at
> horizon kickoff/close; prune what dies, add what the loop discovers.

| # | Risk | Likelihood / Impact | Earliest mechanical signal | Mitigation |
|---|---|---|---|---|
| R1 | **Green in CI, dead on real hardware.** Headless `underruns==0` and fake-device gates don't transfer to real drivers/interfaces | High / Fatal to alpha | A [reality-lane](../reality-lane.md) smoke FAILs — or required PASS evidence is absent | Agents run the one-command smokes on an equipped machine and commit only genuine generated results; missing device, routing or access is reported as a blocker; the Usable-song and alpha gates use packaged-build evidence |
| R2 | **Gates written to go green, not to bite** — the observed H1–H6 failure mode | High / High (false confidence compounds) | A mutation/adversarial pass finds a gate that cannot fail when its code breaks | Every H14–H17 plan has a "Gates that must bite" section naming negative controls at plan time; periodic adversarial review stays in the workflow |
| R3 | **FX parameter identity churn breaks saved projects** (one-way door: ParamIDs, value mappings, and FX chain rows enter user bundles) | Medium / Severe (user data) | The FX-era fixture bundle (frozen at first FX schema version) fails to open or re-render identically | ADR-0038 locks ParamID stability + normalized-value mapping rules; a forever-gate opens the frozen fixture bundle every CI run |
| R4 | **The hosting bet fails late.** The worker boundary has only ever run synthetic passthrough; H18 and the YES-family-as-plugins strategy build on it | Medium / Strategic | Reality-lane smoke 2 (one real VST3 through `YesDawPluginHost`) FAILs, flakes, or cannot run | G4.8/H18 is a separate post–Usable-song milestone and cannot begin plugin feature work until the real-VST3 worker smoke records PASS; missing approved plugin access stays an explicit blocker |
| R5 | **Automation runtime is hollow** — ADR-0009's model exists but no end-to-end consumer has proven the runtime | Medium-high / Medium (rework under a UI already built on it) | H15 checkpoint 0: the audit gate (render an automated ramp, compare to closed form) fails or reveals missing plumbing | H15 is audit-first by decision — no lane UI or persistence lands before the audit gate reports what is real |
| R6 | **Mechanical-verification ceiling at the UX last mile** — parity gates green, but the app *feels* wrong | Medium / Medium-high | Agent rubric review finds a mismatch, or the real-GPU windowed frame gate contradicts the headless one | Design-token LookAndFeel keeps fixes central; agents run screenshot comparison and the mechanical frame gate at each applicable milestone; no routine human eyeball step gates advancement |
| R7 | **Synchronous waveform cache stalls the UI** on real project sizes | High / Medium | H16 async-cache gate: UI-thread-block instrumentation exceeds budget; synchronous-decode negative control passes when it should fail | H16 builds the async peak-pyramid cache with a "UI thread never decodes" invariant test |
| R8 | **Scope creep — the general-purpose trap** for a solo builder (the research's named ship-killer) | Medium / High (usable product never arrives) | Work outside the active milestone enters its checkpoint list or repeatedly delays its exit | The Usable-song milestone is the first bounded product path; unrelated work stays parked, plugin deepening has its own later milestone, and a scope-order change requires an ADR |
| R9 | **Multi-session divergence** — the H13 baton, planning sessions, and other machines working the same repo | Medium / Medium | STATUS.md merge conflicts; a baton re-does or contradicts packet work | STATUS.md is the single handoff; planning packets never open horizons or touch implementation; pull-first/push-last discipline |
| R10 | **Cross-platform float divergence breaks bit-identical gates** once real DSP (denormals, transcendental-heavy FX) lands | Medium / Medium (CI flake erodes trust) | A golden or determinism gate fails on exactly one CI platform | ADR-0038 fixes the denormal/FTZ policy and per-gate tolerance policy explicitly; per-platform goldens are forbidden — root-cause instead |

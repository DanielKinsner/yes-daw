# YES DAW keymap v2

Generated by `YesDawKeymapDoc` from the action descriptors (plan §4; G1.1). Do not edit by hand:
run the tool and commit the result. `Ctrl+Y` is an alias of `Ctrl+Shift+Z`; `Return` of `Enter`;
the numpad's digits and operators spell the same chords as the main keys.

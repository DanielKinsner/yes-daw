## Source and correspondence

`layout.cpp` keeps the frozen Clock's original independent/Time/source-costs header order and all its original system includes, adding only the replica header and cstddef. It declares one external constinit const U64 array in read-only section `.ylayout`, consisting solely of constant compiler expressions. There is no function entry, construction/call, pointer value, mutable object or runtime initializer. Header definitions remain unused except for type/constant queries. No library is linked.

Real public selected types are queried directly: qc::Change/Native/Cut/NumericAClock, engine TempoChange/MusicalTime/SampleRate/CompiledTempoMap, actual source-costs FamilyBound/WholeBound/Catalogue, and the selected std::pair/vector/string/exception/runtime_error/logic_error/array types. `layout-types.h` contains eleven Clock-private outer named type replicas plus nested Picks::Item. Each complete storage declaration, field order, base, private/public access group, member initializer, self/dependent type and special-member property is accounted in `correspondence.json`, alongside the exact WHOLE original definitions. Ordinary nonvirtual method signatures are retained but their bodies are omitted; Rejection's small constructor and virtual what override remain exact. No replica is instantiated. For CachedPort, Meter& names the corresponding Meter replica; self names and namespace differ. Rejection keeps the actual std::exception base, including its polymorphic properties. There is no new pack directive or inheritance simplification.

These are not the original nominal private types. The reviewer must accept the limited selected-ABI inference that identical field/base/access/special-member representation, with only the documented namespace/self-type and nonvirtual-body changes, preserves the queried object layout. Distinct RTTI/vtable contents, behavior and method code are not claimed equal. A replica value without this correspondence review cannot qualify Clock. Public original types do not need this replica inference.

Offsets are emitted only for public fields of types required by static_assert to be standard-layout. Private/nonstandard Rejection/CachedPort/NumericAClock/CompiledTempoMap/Catalogue offsets are not manufactured. References are not queried with sizeof(T&) as if that measured pointer width. Actual Clock lambda closure layouts, hidden return placement, lifetime counts, compiler frame padding/spills/shadow space and stack commitment remain outside this purpose. All source-required real temporaries and object copies still require the separate complete lifetime worksheet.

## Read-only COFF decoding

`decode_coff.py` is source-reviewed now and UNRUN. Later the launcher may invoke its Python file decoder in the same purpose host after exact pin and successful compilation checks. It loads no DLL/native code and never executes object bytes. It accepts only bounded ordinary AMD64 COFF with zero optional header, checked section/symbol/string/aux extents, one external named cell array in one read-only initialized `.ylayout`, no section relocations for those cells, no nonempty executable section and no dynamic initializer symbols. It checks the magic/version/schema cell count and emits actual little-endian U64 values paired with the frozen expressions. Output rows are entirely decoded compiler data, not manually filled sizeof/offset claims. A standalone later file-only decode uses the same object/schema paths and remains a distinct authorized scope.

The schema has no predicted per-type values to rewrite after a failure. Existing type-size inequalities and x64/profile assertions are explicit source hypotheses. A successful compiler/decoder result can qualify only those exact type facts under the reviewed correspondence and pinned profile. It does not complete native payload lifetimes, source prices, module/math equivalence, final binding, full scratch or Clock/supervisor execution gates.

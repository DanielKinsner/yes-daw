# Clock R22 shared controller work

`python -I -S -B shared-schedule.py` checks the pinned runner and
manifest and reconstructs the current occurrence envelope.
`python -I -S -B shared-work.py` composes the shared body prices.
Both scripts read source text and manifest data without loading
the PowerShell runner. The first work-check attempt rejected the
receipt field comparison because its key spelling expression omitted
digits. It now recognizes identifiers such as `source_manifest_sha256`
and compares all five named output-map key sets before counting shapes.

The source check binds 163 written occurrences in the watched helper
families. The work check matches 59 explicitly priced legacy bodies,
nine legacy bodies expanded in named enclosing rows, and the
[separate file hash](README.md#shared-file-hash-body). This accounts
for all 69 byte-identical inherited bodies. The [R13 independent
review](../2026-11-06-clock-r13-runner-census-independent-review-r3/sources/139-review.md)
supplies the older body prices and scalar boundary. The current
manifest, call sites, loop guards and refusal routes supply the
occurrences. The 19 changed or added bodies and the script-level
caller are priced by their separate checks.

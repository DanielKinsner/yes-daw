## Prospective convention: fix before any new prices

Adopt a separately named **research scalar-action convention v1**, subject to independent source review before successor census authoring. It is an algorithmic source model, not instructions, wall time, CPU or RSS. Every priced row must cite the exact source expressions and selected template/library bodies. No optimizer discount or source-to-opaque reclassification is permitted to obtain fit.

| Construct | Required rule |
|---|---|
| Reads/literals | One action per reached scalar value read, including each literal occurrence used as a value. A string literal reference evaluation is one action; characters subsequently visited are actual separate reads. Static literal data formation/storage is a separate fixed obligation, not a repeated full-string copy per reference. |
| Writes/initialization | One per scalar initialization/write; initializer expression actions are additional. `x=0` costs2; `x=y+1` costs4. No default member, fixed aggregate element or actually formed object is omitted. |
| Operators/casts | One for each reached arithmetic, bitwise, comparison, boolean, explicit conversion/cast and conditional selection. Short-circuit operators pay only reached operands plus their own operation. `++x` is read+increment+write; `x+=n` is two reads+add+write. |
| Members/subscripts | A selected scalar field is one value read; the member name is not another value. An independently evaluated receiver/address expression is paid once. Built-in subscript pays base/address/index evaluation and selected element access. A library operator[] also pays dispatch, bindings and actual pinned body. Nested hashtable indexing pays every key/receiver/index step. |
| References/arguments | Each evaluated lvalue address/reference is paid once at the caller. Passing by reference does not copy the referent. Each by-value scalar/field copy pays its source read and destination binding/write. Receiver and every argument expression are explicit caller work. |
| Calls/parameters | Caller dispatch is one; callee entry and each actual parameter initialization are separate. `f(x,7)` has caller x-read+literal+dispatch=3 before callee bindings/body. Calls to empty wrappers still pay their real caller/entry/return source. |
| Returns/branches | A returned value is read and returned; every actual field in an aggregate result is initialized. Explicit or implicit function exit is counted. Every reached if/conditional/switch branch selection and applicable throw/continue/break counts. Do not add all mutually exclusive failures to a path; cover the largest successful prefix plus its applicable refusal, unwind and footer. |
| Loops | Count setup, every condition, entry, binding, increment and terminal false/break/throw path. For PowerShell foreach, the proposed public-source abstraction pays acquisition/state setup, four actions per visited element (test/branch/binding/entry) and two for final false; visible receiver/argument expressions are additional. Hidden interpreter mechanics remain opaque. An independent critic must confirm this rule against the actual successor loops before prices are fixed. |
| Default/aggregate elements | Every scalar whose lifetime is actually formed has an initialization/lifetime action. A supplied explicit or implicit default scalar value also has its value action. Thus zero-initialized array elements are not one free bulk assignment. Uninitialized storage is not falsely reported as zeroed; actual later writes/copies are separate. Enumerate element count, trivial/constructor bodies and retirement source. |
| Copies/moves/elision | Count all semantically possible named-return copy/move source for an upper when NRVO is optional, including full Text arrays and SDK moves/copies. Count guaranteed C++17 prvalue construction once, with its fields, and do not invent an additional guaranteed-elided copy. Source-value/reference ownership and elision assumptions are written per call site. |
| Instrumentation | Catalogue lookup, validation, checked quotation/composition, Meter/Spend/check/admission, receipt construction and cleanup are real source work. Reserve a finite nonrecursive administration schedule in the same whole ledger; each action has one exclusive owner. An already reserved row is not executed again just because its price is read. Debit arguments are data, never evidence of that many actual actions. |
| Libraries/primitives | Expand visible SDK/STL/helper source, template selection, iterator, allocator wrapper, object construction/copy/retirement and error branches. Bulk OS/CRT/CLR/libm primitive internals remain the same explicitly unqualified boundary. Their visible callers/wrappers count. No new primitive category may hide visible work. |
| Checked arithmetic/data | Every count, product, round-up, source sum, byte/slot/escape bound and ledger composition has a finite integer domain with checked overflow. Zero/unbound/default prices cannot masquerade as complete rows. Constant-data construction and actual future Catalogue storage/lifetime are explicit fixed obligations even if the compiler performs constant initialization. |

These rules are prospective. The pinned R4 lower proof remains accepted only under its written convention and scope.

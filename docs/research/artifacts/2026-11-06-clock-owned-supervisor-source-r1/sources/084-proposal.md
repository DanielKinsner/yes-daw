# R14 complete owned-supervisor source proposal — UNRUN

This is source authoring under ADR0090 and its accepted source plan. The parent
owns independent acceptance, Git and any later purpose/execution lane. No target
PowerShell parsing, importing, compiler, helper, fixture, Clock, GUI or device
execution is performed by this author. All execution flags are false and both
target and helper Data are undefined. No old price, fit, geometry or native
association is transferred. The scope is a complete implementation candidate,
not an accepted implementation or a claimed resource certificate.

The five native files are under `native/`. The R14 five-file runner/oracle sibling
is `build-ci/musical-audio-persistent-planner-certification/source-revisions/clock-oracle-r14-owned-supervisor-source-r1/`.
This keeps the byte-exact target's relative independent-clock include valid.
`author.py` performs only ordinary source/text/JSON/hash/integer transforms;
`runner-supervisor.ps1.fragment` is data used in that transformation, never an
imported helper. Author-attempt snapshots preserve the complete inputs to each
authoring invocation. The diagnostic-gap snapshot separately preserves the
initial, rejected conflation of job termination and job query errors. It is not
an execution failure. The parent is obtaining the narrow protocol correction
before any complete source freeze. Accepted ADR0091 now authorizes the exact v2
magic/version/run-domain/reason48 change; actual queries remain reason32.

`sup_core.cpp` owns checked source debits, shared prefix/tail admission, immutable
first/secondary failures and a complete integer SHA256 implementation.
`sup_codec.cpp` owns LE request/terminal fields, UTF16 guards, current request
recipe/digests, argument quoting, eight-key environment and terminal validation.
`sup_io.cpp` owns current path/reparse checks, exact file reads/hashes, stage
enumeration/admission, capture files/pipes/NUL, creation-time job attributes,
contained target creation and one-time terminal publication.
`sup_main.cpp` owns the two reader state machines, event/ack/Stop protocol,
coordinator/deadline, cleanup groups, outcome freeze and nonreturning exit.
`sup.h` declares every typed owner and the future immutable catalogue; no Data
definition, zero-price fallback, runtime magic allowance or accepted ABI appears.

Only the coordinator mutates terminal observations and error records. Workers
publish one immutable logical result and wait for acknowledgement. A ready-event
acquire or actual thread-exit acquire precedes reads of worker data. Full and
EOF-short results account successful bytes once; an EOF-short's next logical
zero requires no extra native read. Error-local partial bytes are separately
recorded and never added to the old observed counter. The coordinator can consume
one final ready result in the prepaid tail without writing or cap omission.
Unsettled mutable partials are unavailable; the live buffer/frame stays owned.

Read and write tickets use the same SRW state as BeginTail. A ticket admitted
before the cut may complete afterwards. No new ticket is admitted after the
cut; no new prefix debit is appended. Workers can request the cut without writing
the terminal; the coordinator copies its observation and records meter refusal.
All post-cut operations are paid by the separately derived complete tail, not
unused prefix credit. Tail work is not reported as measured actual usage.

The source has no per-byte async/task/registration graph and no host process
enumeration. It requests normal selected executable/thread stacks rather than
an arbitrary reserve. Explicit thread frames/stacks, request/raw-path/command/
environment/hash/terminal/reader buffers, native handle/job/event/attribute
owners and all copies remain counted. The attribute allocation requests the
exact independently qualified InitializeProcThreadAttributeList extent from
Data, checks the current API's result before HeapAlloc, and never invents an ABI
number. General CRT/CLR/native bookkeeping is unqualified, not zero/exempt.
Ordinary `wmain` CRT/TLS/argv/environment/cold effects are an explicit remaining
native/profile premise. Own source uses GetCommandLineW with its bounded parser,
does not use CRT argv to decode the request, does not read ambient environment
or stdin, and does not write stdout/stderr.

Every actual log WriteFile and short-write continuation follows a fresh complete
stage scan. No snapshot-only, quiet-output or whole1MiB reservation replaces
that guard. Confirmed writes and physical position observations stay distinct.
The private transport files are outside stage and add zero stage bytes, but
their buffers/paths/partial files/namespace and whole retained/scratch source
owners are included. Target/stdin pipes preserve default pipe-size requests and
explicit NUL semantics. No kernel pipe-buffer size is invented.

Target exit requires an observed signaled process handle and a successful
exit-code query, copied before reference release. Raw259 is not treated as
liveness. Job termination/cancellation/close are attempts, never settlement
proof. A current successful empty-job query is still conditional on selected
Windows job/reference/nested-profile semantics. Partial returned process/thread
owners are retained and force quarantine. Failed closes have no release credit.
Unresolved worker state is never unwound/recycled; source uses a nonreturning
ExitProcess boundary after preserving the prefix record. All such unknown owners
remain in the whole reservation and the parent forbids another child.

The parent explicitly supplies the helper's eight expanded values, no redirected
helper streams and one request16 argument. The trusted launcher must separately
qualify null/noninteractive helper stdin and error-dialog behavior. Target NUL
is a new explicit inheritable handle in the exact three-element handle list.
Creation-time job membership and creator-death behavior remain a native proof
premise; CREATE_SUSPENDED plus a later manual assign is not substituted.

The parent validates fixed length/EOF, every current identity, integer pair,
availability flag, progress equation and completion matrix before projecting
the unchanged child keys. Missing data is null. A complete nonzero target exit
is preserved then refused as the actual target exit. A valid prefix survives a
late helper failure, but global quarantine and the tail/transport failure carrier
prevent status0/1 from certifying unobserved tail work. Native primary, first
secondary and dedicated first native-secondary evidence remain in the immutable
terminal and bounded local exception carriers; raw byte arrays/tuples/carriers
do not enter a JSON graph. Existing controller first-primary/secondary slots and
outer before/after input/binary fences retain their ordering.

new native files, with a closed native-source namespace. The helper binary has
